# H5 tab-root section fragments

Composable blocks for `h5_page_sections.compose_tab_root_vue()`.

| Directory | Purpose |
|-----------|---------|
| `vue/` | Section markup fragments |
| `css/` | Styles emitted when section is active |
| `scripts/` | Per page-type `<script setup>` logic hooks |
| `shell/` | Tab-root wrapper (TopBar + page-shell + TabBar) |

Blueprint: `scripts/batch/h5_page_sections.py` → `TAB_ROOT_BLUEPRINT`.
