# H5 壳业务流程文字版

Bridge 级**逐步菜谱**：H5 触发 → 壳执行 → 回 H5 → H5 消费。PM 在 `功能文档.md` 引用本章编号；Programmer 按 task.csv 七维实现对应语法。

**全局禁止**：base64 传图/传文件。

---

## 0. 跨能力约定

- 路径：仅存 `Documents/` 相对路径。
- 权限拒：英文单行弹窗，不跳设置。
- 每包实现语法以 CSV 中 `bridgeCallStyle` / `bridgeCallbackStyle` / `bridgeEnvelope` / `mediaServe` 为准；下列步骤中的示例 API 名仅为**语义等价**示意。

---

## 1. pickImage（拍照/相册）— B01

### 1. H5 触发
用户点击 **Add Photo**。

### 2. H5 → Flutter
（示例：`callHandler` 风格）
```javascript
window.flutter.callHandler('pickImage', { source: 'camera' }); // 或 'gallery'
```

### 3. Flutter 侧
- `permission_handler` 请求相机或相册权限
- `image_picker` 打开原生相机/相册
- 用户完成或取消

### 4. Flutter 落盘（成功）
- `getApplicationDocumentsDirectory()`
- 保存 `Documents/selfies/week_{N}_{timestamp}.jpg`
- 仅保留相对路径 `selfies/week_1_1719000000.jpg`

### 5. Flutter → H5
```javascript
// 示例：postMessage + 版本化信封
{ "v":1, "action":"imageSelected", "payload":{ "path":"selfies/week_1_1719000000.jpg" }, "error":null }
```

### 6. H5 显示（按 `mediaServe`）

| mediaServe | H5 写法 |
|------------|---------|
| InAppLocalhostServer | `<img src="http://127.0.0.1:{port}/selfies/...jpg">` |
| shouldInterceptRequest+appassets | `<img src="https://appassets.example/selfies/...jpg">` |
| shelf / HttpServer.bind | `<img src="http://127.0.0.1:{port}/selfies/...jpg">` |

**禁止** `file://` 与 base64。

### 7. 异常
- 取消 → `error.code = USER_CANCELLED`
- 权限拒 → `PERMISSION_DENIED`
- 无相机 → `CAMERA_UNAVAILABLE`

## 2. saveImageToAlbum — B02

1. H5 点 **Save to Photos**，传 `path`（相对路径）。
2. Bridge `saveImageToAlbum({ path })`。
3. 壳读 Documents 文件 → `gal` / 相册 API。
4. 回调 `saveSuccess` / `PERMISSION_DENIED`。
5. H5 Toast 反馈。

---

## 3. startRecord / stopRecord — B03

1. H5 点 **Record** → `startRecord({ maxSeconds })`。
2. 壳请求麦克风 → `record` 插件写入 `voice/{id}.m4a`。
3. H5 点 **Stop** → `stopRecord()` → 回 `{ path: 'voice/xxx.m4a' }`。
4. H5 用 `mediaServe` 方案播放预览（同 §1.6）。

---

## 4. playAudio — B04

1. H5 传相对路径 `playAudio({ path })`。
2. 壳用 `audioplayers` 播放 Documents 内文件（勿用 VideoPlayer 播音频）。
3. 回调 `playStarted` / `FILE_NOT_FOUND`。

---

## 5. readFile / writeFile — B05

1. `readFile({ path })` → 壳读文本/小文件，回 `{ content }` 或错误。
2. `writeFile({ path, content })` → 壳写 Documents。
3. 大文件/binary 优先走 pickImage 流程，不走 readFile 塞入内存。

---

## 6. getDeviceInfo — B06

1. H5 启动或旋转时 `getDeviceInfo()`。
2. 壳回 `{ safeArea: {top,bottom,left,right}, appVersion, locale }`。
3. H5 用于布局 `padding` 与版本展示。

---

## 7. openExternalUrl — B07

1. H5 点外链 → `openExternalUrl({ url })`。
2. 壳 `SFSafariViewController` 或 `url_launcher` 外链。
3. **不在**主 WebView 内导航到第三方域。

---

## 8. copyToClipboard — B08

1. `copyToClipboard({ text })` → 壳写剪贴板 → `copied: true`。

---

## 9. purchase — B09

见《H5壳IAP协议.md》全文。

---

## 10. getLegalUrls — B10

1. H5 设置页点协议 → `getLegalUrls()`。
2. 壳回 `{ privacyUrl, termsUrl }`（常量文件 HTTPS）。
3. H5 可请求壳 `openLegalWebView({ which: 'privacy' })` 或自开内嵌页。

---

## 11. reload / goBack — B11

1. `reload()` → 壳主 WebView reload `assets/h5/index.html`。
2. `goBack()` → 壳 `WebView` history back（若 H5 未完全 SPA）。

## 附录 B：Swift 壳实现差异

`h5_swift_shell` 与 Flutter 壳在调用语法上语义等价，但 Native 侧实现不同。以下列出关键差异点，详细代码见《H5壳Swift实现规范.md》。

### B1. WebView 初始化

- 使用 `WKWebViewConfiguration`。
- 自定义 scheme 通过 `config.setURLSchemeHandler(_:forURLScheme:)` 注册。
- Bridge bootstrap 通过 `config.userContentController.addUserScript(_:)` 在 `.atDocumentStart` 注入。

### B2. Bridge 调用方式

| 风格 | H5 → Native | 说明 |
|------|-------------|------|
| WKScriptMessageHandler（默认） | `window.webkit.messageHandlers.<name>.postMessage(msg)` | Native 实现 `WKScriptMessageHandler` |
| iframe URL scheme | `iframe.src = '<scheme>://invoke?callbackId=...&action=...&data=...'` | Native 在 `WKNavigationDelegate.decidePolicyFor` 拦截 |

Native → H5 统一走 `webView.evaluateJavaScript("window.<callbackFn>(callbackId, envelope)")`。

### B3. 媒体服务

- Swift 使用 `WKURLSchemeHandler` 服务 `{appslug}-asset://local/<relPath>`。
- 优先读 `Documents/<relPath>`，不存在则 fallback 到 `Bundle.main` 中的 seed 资源。
- 禁止 `file://` 与 base64。

### B4. IAP

- 使用 StoreKit 2：`Product.products(for:)` 查询，`product.purchase()` 购买。
- 交易成功后本地记录 `fulfilledTransactions` 去重；**当前未做服务端 receipt 验证**。

### B5. 启动闪屏

- iOS `LaunchScreen.storyboard` 提供首屏占位。
- Swift 侧实现 `LaunchVeil`（`UIViewController` 或 SwiftUI `View`）。
- `shellReady` 收到后延迟一帧撤 Veil。

### B6. 去风味

- Swift 侧负责容器级：隐藏滚动条、透明背景、键盘辅助栏处理、双击缩放。
- 具体实现可用 swizzle，但须注意其侵入性。
