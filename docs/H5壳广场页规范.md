# H5 壳广场页规范

> **Bridge 验权页**：浏览器无法测原生能力时，在模拟器/真机通过隐藏入口进入，逐项点通 Bridge。

## 1. 定位

| 项 | 约定 |
|----|------|
| 路由 | `#/plaza`（hash-router 等价写法可接受） |
| 可见性 | **隐藏入口**；提审包 **保留** 路由与页面，**禁止**进 Tab / 主导航 |
| 入口手势 | Settings（或 About）页 **长按版本号 3 秒** → `router.go('#/plaza')` |
| 实现方式 | **半硬编码**：按钮集合由 `bridgeCapabilities` / 功能文档勾选决定 |

## 2. 标准按钮矩阵

按本包启用 Bridge 能力渲染；未启用 **不渲染** 对应按钮。

| 按钮标签（英文） | Bridge | 启用条件 |
|------------------|--------|----------|
| Record / Stop | `startRecord` / `stopRecord` | 录音 |
| Play Audio | `playAudio` | 播放 |
| Camera | `pickImage` `{ source: 'camera' }` | 选图 |
| Gallery | `pickImage` `{ source: 'gallery' }` | 选图 |
| Save to Photos | `saveImageToAlbum` | 写图库 |
| Test Purchase | `purchase` `{ productId: '311400' }` | IAP（**广场测购固定 311400**，非 catalog SKU） |
| Pick Video | `pickVideo`（协议扩展） | 功能文档声明视频 |

每按钮须有三态反馈：**calling** / **success**（展示 path 或 mediaServe 预览）/ **error**（`shell/permission_gate` + `shell/bridge_toast`）。

## 3. Component Kit 引用

| 能力 | Kit ID |
|------|--------|
| 按钮 | `primitives/button` |
| 结果提示 | `shell/bridge_toast` |
| 权限拒 | `shell/permission_gate` |
| 选图 | `data_display/media_picker` |
| IAP 试购 | `patterns/gem_store_layout`（最小单 SKU 条，勿整店复制） |
| 页面壳 | `shell/bridge_plaza` |

## 3.5 组件层约定

- **class 前缀**：`c-{prefix}-plaza-*`
- **render 函数**：`renderPlaza`（或 kit 命名空间等价物）
- **变体**：
  - `standard`：标准按钮矩阵
  - `with-video`：额外 `pickVideo` 按钮（功能文档声明视频时启用）
- **生产入口**：Settings（或 About）页 **长按版本号 3 秒** → `router.go('#/plaza')`
- **开发入口**：可添加明显入口（如 Settings 页可见按钮、悬浮 FAB），但 **必须** 用 `H5_PLAZA_DEV_ENTRANCE_START` / `H5_PLAZA_DEV_ENTRANCE_END` 标记包裹，部署前由流水线自动剥离
- **开发提示**：浏览器须走 `browserMock`（`tryBrowserBridgeMock`）假成功，**禁止**因 `Bridge unavailable` 卡死业务流；真机/模拟器经壳 WebView + Plaza 验原生能力。

## 4. 禁止

- 广场页作为 Welcome 后默认落地页
- 在 Tab bar 或 Home hub 暴露「Plaza / Debug」入口
- 使用 `<input type="file">` 代替 Bridge（**例外**：仅允许在 `h5/src/bridge/browserMock.ts` 内实现浏览器选图）
- 静默失败（权限拒须 snackbar / error_state）
- 浏览器无壳时对 `pickImage` / `saveImageToAlbum` / `startRecord` / `stopRecord` / `playAudio` 硬 `reject('Bridge unavailable')`

## 5. 开发流程

1. **浏览器**：开发业务 SPA + 广场页 UI；Bridge 无壳时走 **browserMock resolve**（见 `data/static/h5_snippets/bridge/`），保证有图/有录音后的流程可继续调 UI
2. **模拟器**：壳 `h5EntryUrlDev` 指向局域网静态服 → 长按版本号进 plaza → 点通各项
3. **上线前**：
   - 运行 `strip_plaza_dev_entrance(h5SiteRoot)` 剥离开发入口；
   - 人工部署 `h5SiteRoot` → `h5EntryUrlProd`；壳切 URL 后再验 plaza
   - **真机 Plaza** 为原生能力最终验收（mock 不计入）

### Swift 壳验权注意

- Swift 壳须确保 `getProducts`、`pickImage`、`purchase` 等 Bridge 在广场页能正常响应。
- 真机/模拟器上通过 `h5EntryUrlDev` 加载 LAN H5 时，注意 ATS：Release 配置只允许 HTTPS 生产域名；Debug 可临时允许局域网 HTTP（在 `Info.plist` 中配置 `NSExceptionDomains` 或 `NSAllowsLocalNetworking`）。

## 5.5 开发入口标记规范

为提升联调效率，可在开发包中把广场入口做明显，但 **必须** 按以下格式标记，供部署前自动移除：

```html
<!-- H5_PLAZA_DEV_ENTRANCE_START -->
<button class="c-{prefix}-plaza-dev-entrance" data-action="go-plaza">Plaza</button>
<!-- H5_PLAZA_DEV_ENTRANCE_END -->
```

```javascript
/* H5_PLAZA_DEV_ENTRANCE_START */
function initPlazaDevEntrance() { /* 绑定明显入口事件 */ }
/* H5_PLAZA_DEV_ENTRANCE_END */
```

规则：
- `H5_PLAZA_DEV_ENTRANCE_START` 与 `H5_PLAZA_DEV_ENTRANCE_END` 必须各占一行；
- 部署前若仍检测到标记，H5 Bundle Gate 会报 **软警告**（不阻断，但需人工确认）；
- 禁止把明显入口直接写进生产代码而不加标记。

## 6. Gate

- 软警告：站点 JS/HTML 未见 `#/plaza`
- 软警告：未见 Bridge 验权调用（`pickImage` / `purchase` 等）
- 软警告：检测到未剥离的 `H5_PLAZA_DEV_ENTRANCE_*` 标记或明显入口
