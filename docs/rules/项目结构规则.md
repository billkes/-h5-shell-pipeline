# 项目结构规则

## h5-shell-pipeline 根目录

```
h5-shell-pipeline/
├── task.csv                    # 唯一批次台账
├── run.sh / run.ps1 / run.bat  # 入口脚本
├── scripts/batch/              # Python 跑批流水线（python3 -m batch）
├── output/                     # 产出目录
├── data/                       # 流水线数据（deck、模板、静态资源）
│   ├── decks/                  # Bridge 七维牌池
│   ├── static/                 # 静态模板
│   │   └── templates/
│   │       └── swift_shell/    # h5_swift_shell 厂包夹板
│   └── registry/               # 登记表
├── docs/                       # 全部说明文档
│   ├── rules/                  # 仓库级规则（本目录）
│   └── H5-Bridge协议.md
│   └── H5壳Swift实现规范.md
│   └── ...
├── prompts/                    # Agent prompt 模板
└── config/                     # config.yaml 等
```

**原则**：批量逻辑写在 `scripts/batch/` 内，入口统一为 `PYTHONPATH=scripts python3 -m batch`（`./run.sh` 已配置）。批次台账为根目录 **`task.csv`**。

## H5 Shell 流水线 Phase

| Phase | 说明 |
|-------|------|
| 1 | PM / Plan：功能文档、产包计划 |
| 2 | UI：视觉蓝图、去风味规范 |
| 3 | H5：业务 SPA 开发 |
| 4 | Shell：Flutter / Swift / OC 壳实现 |
| 5 | 配图与资源 |
| 6 | 编译与 Gate |
| 7 | 自审与风控 |
| 8 | 测试 |
| 9 | 录屏与交付 |

Prompt 模板：`prompts/h5_shell/phase_h5_shell_*.txt`、`prompts/h5_shell/phase_h5_shell_swift_programmer.txt` 等。

## 输出结构

Agent 产包工作区（按 `pack_type` 命名外层容器，对齐 Swift / OC 厂包约定）：

```
output/{AppName}-Swift/{AppName}/     # h5_swift_shell
output/{AppName}-OC/{AppName}/        # h5_oc_shell
output/{AppName}-Flutter/{AppName}/   # h5_shell / h5_flutter_shell
```

`build-all` 模板构建为平铺单层：`output/{AppName}/`。

产包完成后典型内容：

```
output/{AppName}-Swift/{AppName}/
├── 本包登记信息.json
├── _preview/                   # preview.tabs 产物（提交 Git；壁纸 PNG + HTML + canonical）
├── h5/                         # H5 业务包（按包差异化）
└── ios/                        # Native 壳（Swift / OC）
    └── {AppName}/
```

## 禁止

- 业务源码、编译产物、**`h5_site/` 部署产物**、图片、凭证、私密 JSON/密钥 等禁止提交到 **h5-shell-pipeline 主仓**。
- **`_preview/`** 在 **per-app Git 仓**（`output/{App}-Swift/` 等）内**须提交**；仅 `**/_preview/wallpaper/node_modules/` 忽略。
- 禁止在根目录乱放 `.md`、`.txt`、`.csv`，批次外文件须进入 `docs/`、`data/`、`scripts/` 或 `tmp/`。
