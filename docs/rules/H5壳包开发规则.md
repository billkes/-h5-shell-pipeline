# H5 壳包开发规则

## 适用

全部 `h5_shell` / `h5_flutter_shell` / `h5_swift_shell` / `h5_oc_shell` 包。

## 核心约束

1. **无可见业务 UI 在 Native**：Welcome / Legal / TabBar / Shop 等业务页面必须放在 H5 内。
2. **单文件入口**：H5 构建产物须为 `h5_monolith` 单文件（Vite + vite-plugin-singlefile），复制为 `ios/{AppName}/{AppName}.html` 或 Flutter 等价位置。
3. **Bridge 七维锁定**：
   - `h5_swift_shell` 锁定 `wkwebview_swift`、`WKScriptMessageHandler`（或 iframe URL scheme）、`WKURLSchemeHandler local vault` 等
   - `h5_oc_shell` 锁定 `wkwebview_oc`（见 `docs/H5壳OC实现规范.md`）
   - `h5_flutter_shell` 按 deck 抽卡
4. **本地资源**：禁止 `file://`、禁止 base64 大图；媒体走自定义 scheme（如 `prepoo-asset://`）。
5. **权限**：权限拒弹窗英文单行，不跳设置。
6. **IAP**：取消购买无失败弹窗；真失败英文 Alert；交易成功后本地去重，未做服务端验单需额外实现。
7. **去风味**：隐藏滚动条、去键盘辅助栏、禁双击缩放、H5 侧 `spellcheck="false"`。
8. **启动闪屏**：LaunchScreen + LaunchVeil 与 H5 首屏同色；`shellReady` 后撤 Veil。
