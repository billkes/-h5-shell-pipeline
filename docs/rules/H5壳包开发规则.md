# H5 壳包开发规则

## 适用

全部 `h5_shell` / `h5_flutter_shell` / `h5_swift_shell` / `h5_oc_shell` 包。

## 核心约束

1. **无可见业务 UI 在 Native**：Welcome / Legal / TabBar / Shop 等业务页面必须放在 H5 内。
2. **单文件入口**：H5 **源码**在 `h5/`（Vue 3 + Vite）；流水线 **`dev.h5.build`** 编译为 `h5_site/{appSlug}/index.html`（**部署产物，不提交 Git**）。**无仓库 H5 代码模板** — Agent 按 `docs/H5壳Vite工程规范.md` 从零创建 `h5/`。
3. **Bridge 七维锁定**：
   - `h5_swift_shell` 锁定 `wkwebview_swift`、`WKScriptMessageHandler`（或 iframe URL scheme）、`WKURLSchemeHandler local vault` 等
   - `h5_oc_shell` 锁定 `wkwebview_oc`（见 `docs/H5壳OC实现规范.md`）
   - `h5_flutter_shell` 按 deck 抽卡
4. **本地资源**：禁止 `file://`、禁止 base64 大图；媒体走自定义 scheme（如 `prepoo-asset://`）。
5. **权限**：权限拒弹窗英文单行，不跳设置。
6. **IAP**：取消购买无失败弹窗；真失败英文 Alert；交易成功后本地去重，未做服务端验单需额外实现。
7. **去风味**：隐藏滚动条、去键盘辅助栏、禁双击缩放、H5 侧 `spellcheck="false"`；**禁 `<audio controls>`**（自定义 `AudioPlayer`）。
8. **WKWebView 性能/层叠**：Tab `keep-alive`、App 级缓存 `TabLayout`、功能页 ambient 静化、禁大面积 `backdrop-filter`、z-index 阶梯（media > event）、Teleport 弹层 `onDeactivated` 清理。见 `docs/H5壳WKWebView性能与层叠规范.md`。
9. **启动闪屏**：LaunchScreen + LaunchVeil 与 H5 首屏同色；`shellReady` 后撤 Veil。

## 技能仓库产物清单（V3 流水线）

由 `ui-ux-pro-max-skill` 脚本步骤写入 workspace，Agent 只扩写不另造 UI 规范：

| 步骤 | 产物路径 | 用途 |
|------|----------|------|
| `skill.design` | `MASTER.md` · `candidates.json` · `stack-html-tailwind.md` · `stack-vue.md` · `h5-runtime.md` | 设计系统 + skill 双栈 |
| `skill.enrich` | `ux-checklist.md` · `icon-brief.md` · `typography-brief.md` · `h5-interface-brief.md` | UX/图标/字体检索 |
| `skill.adapt` | `design-brief.md` · `design-tokens.css` · `icon-manifest.json` | 选型与实现 brief |
| `skill.pages` | `design-system/{app}/pages/*.md` | 逐屏 override（覆盖 MASTER） |
| `skill.tokens` | `skill-adapt/design-tokens.json` · `design-tokens.css` | CSS 变量同步 |
| `preview.tabs` | `_preview/{appSlug}-tabs-preview.html` · `_preview/preview-canonical.md` · `skill-adapt/preview-approved-colors.json`（流水线从 canonical 解析） | Tab 明暗静态预览（**提交**至 per-app Git；仅忽略 `_preview/wallpaper/node_modules`） |
| `build.agent` | 功能文档 / 视觉蓝图 / **整棵 `h5/`** | Agent 自建 Vite + 全页 UI；规范见 `docs/H5壳Vite工程规范.md` + pages/*.md |
| `dev.h5.build` | `h5/` → `h5_site/{prefix}_entry.htm` | Vite 单文件编译；**不拷贝页面模板** |

配置：`config.yaml` → `uupm.integrations` 可关闭单项；`design.gemini_api_key` 可选启用 Logo brief。
