# H5 壳包开发规则

## 适用

全部 `h5_shell` / `h5_flutter_shell` / `h5_swift_shell` / `h5_oc_shell` 包。

## 核心约束

1. **无可见业务 UI 在 Native**：Welcome / Legal / TabBar / Shop 等业务页面必须放在 H5 内。
2. **单文件入口**：H5 **源码**在 `h5/`（Vue 3 + Vite）；流水线 **`dev.h5.build`** 编译为 `h5_site/{appSlug}/index.html`（**部署产物，不提交 Git**）。
3. **Bridge 七维锁定**：
   - `h5_swift_shell` 锁定 `wkwebview_swift`、`WKScriptMessageHandler`（或 iframe URL scheme）、`WKURLSchemeHandler local vault` 等
   - `h5_oc_shell` 锁定 `wkwebview_oc`（见 `docs/H5壳OC实现规范.md`）
   - `h5_flutter_shell` 按 deck 抽卡
4. **本地资源**：禁止 `file://`、禁止 base64 大图；媒体走自定义 scheme（如 `prepoo-asset://`）。
5. **权限**：权限拒弹窗英文单行，不跳设置。
6. **IAP**：取消购买无失败弹窗；真失败英文 Alert；交易成功后本地去重，未做服务端验单需额外实现。
7. **去风味**：隐藏滚动条、去键盘辅助栏、禁双击缩放、H5 侧 `spellcheck="false"`。
8. **启动闪屏**：LaunchScreen + LaunchVeil 与 H5 首屏同色；`shellReady` 后撤 Veil。

## 技能仓库产物清单（V3 流水线）

由 `ui-ux-pro-max-skill` 脚本步骤写入 workspace，Agent 只扩写不另造 UI 规范：

| 步骤 | 产物路径 | 用途 |
|------|----------|------|
| `skill.design` | `design-system/{app}/MASTER.md` · `candidates.json` · `stack-*.md` · `stack-h5-vite.md` | 设计系统主文件 |
| `skill.enrich` | `design-system/{app}/ux-checklist.md` · `icon-brief.md` · `h5-interface-brief.md` | UX/图标/H5 规范检索 |
| `skill.adapt` | `skill-adapt/design-brief.md` · `css-motion-brief.md` · `icon-sprite-manifest.json` | 选型与实现 brief |
| `skill.pages` | `design-system/{app}/pages/*.md` | 逐屏 override（覆盖 MASTER） |
| `skill.tokens` | `skill-adapt/design-tokens.json` · `design-tokens.css` | CSS 变量同步 |
| `dev.h5.build` | `h5/` → `h5_site/{prefix}_entry.htm` | Vite 单文件编译 |
| `dev.h5.gate` | （门禁报告，无文件） | H5 bundle + UX 脚本校验 |

配置：`config.yaml` → `uupm.integrations` 可关闭单项；`design.gemini_api_key` 可选启用 Logo brief。
