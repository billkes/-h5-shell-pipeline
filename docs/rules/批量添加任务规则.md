# task add：往 task.csv 增行

## 用户说「往 task 加 N 行 / N 个包」时

**当前阶段**：h5-shell-pipeline 尚未接入飞书自动主题库与命名生成，请按以下方式操作：

### 方式一：初始化空行后手填（推荐当前使用）

```bash
cd h5-shell-pipeline
./run.sh task-init --batch-id <batchId> --rows N
# 然后打开 task.csv 人工填入：应用主名称、全称、首个商品Code、仓库地址、主题列、Bridge 七维等
./run.sh task-validate
./run.sh task-ready
```

### 方式二：追加空行

```bash
./run.sh task-add --rows N
```

### 方式三：产包

```bash
export H5_PROD_HOST="test.darin.beauty"
export BUNDLE_ID_PREFIX="com.example"
export APPLE_TEAM_ID="YOURTEAMID"
./run.sh build-all
```

## Agent 禁止

- 手编/猜测 主题编号、全称、首个商品Code（须与在线表/主题库对齐）
- 读 `43-analysis/` 填 task
- 在 run 阶段做任何 audit / 拉产A
- 用 `task init` 空行 + 手填绕过校验

## 校验

- `task-validate`：基础必填与格式校验。
- `task-ready`：产包前严格校验（去重、Bridge 七维、URL 格式等）。

## 失败时

- 校验失败 → 按提示补充缺失字段后再 `task-ready`。
- audit 仍失败 → 报告用户，勿绕过 ready 直接 run。
