# 主题防火墙说明

## 背景

批次主题已统一来自主题库（`data/registry/themes-cn.txt` 或外部飞书主题库），不再由 Agent 现编主题。

原「推荐方向 regex、黑名单选题」等逻辑**已移除**——与主题库工作流冲突。

## 跑批入口

`python3 -m batch` 在消费队列前调用 `task-ready`，当前已实现：

| 检查项 | 说明 |
|--------|------|
| 批次内「首个商品Code」去重 | 防 IAP Product ID 撞车 |
| 批次内「全称」去重 | 防 App Store 副标题重复 |
| 批次内「应用主名称」去重 | 防包名重复 |
| CSV 必填字段 | 应用主名称 / 全称 / 状态管理 / 架构 / 命名混淆 / 首个商品Code / 仓库地址 / 编程风格 / 应用类型 |
| Bridge 七维（H5 shell） | webviewEngine / bridgeCallStyle / bridgeCallbackStyle / bridgeEnvelope / mediaServe / bridgeErrorCode / bridgeInjectTiming |

**尚未实现**：contentpack-registry 主题相似度、跨批次 4.3 防关联（待后续）。
