# 主题防火墙说明

## 背景

批次主题已统一来自主题库（`data/registry/themes-cn.txt` 或外部飞书主题库），不再由 Agent 现编主题。

原「推荐方向 regex、黑名单选题」等逻辑**已移除**——与主题库工作流冲突。

## 跑批入口

`python3 -m batch` 在消费队列前调用 `task-ready`，当前已实现：

| 检查项 | 说明 |
|--------|------|
| 批次内「首个商品Code」去重 | 防 IAP Product ID 撞车 |
| 批次内「全称」去重 | 防 App Store 副标题重复 |
| 批次内「应用主名称」去重 | 防包名重复 |
| CSV 必填字段 | 应用主名称 / 全称 / 状态管理 / 架构 / 命名混淆 / 首个商品Code / 仓库地址 / 编程风格 / 应用类型 |
| Bridge 七维（H5 shell） | webviewEngine / bridgeCallStyle / bridgeCallbackStyle / bridgeEnvelope / mediaServe / bridgeErrorCode / bridgeInjectTiming |
| **contentpack-registry 同名拦截** | 主名称已在 `data/registry/contentpack-registry.json` 登记则阻断 |
| **contentpack-registry 主题相似度** | Jaccard / 布局三重 / Innovation Tab 名与历史包比对（`audit_task_registry_similarity`） |

## 产包登记

- **登记表**：`data/registry/contentpack-registry.json`（与 A-Crush 对齐，勿用空的 `h5-shell-registry.json`）
- **写入时机**：`plan.gate`（步骤 6）成功后，读取工作区 `本包登记信息.json` 并 `append_to_registry`
- **重跑**：`--force` 时 upsert 同名条目；无工作区断点且已登记则 orchestrator 跳过
