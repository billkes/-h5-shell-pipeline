# 主题防火墙说明 — 自拟主题版

## 背景

批次主题来自 **自拟 brief**（一句话 → CSV 六列），**不再**依赖 `themes-cn.txt` 或飞书主题库抽题。

`task pick-theme` 已废弃；4.3 防线前移到 **叙事 audit + interaction topology 批内去重**。

## 跑批入口

`task-ready`（`validate_batch_firewall`）硬拒项：

| 检查项 | 说明 |
|--------|------|
| 批次内「首个商品Code」去重 | 防 IAP Product ID 撞车 |
| 批次内「全称」「应用主名称」「中文主题」去重 | 防包名/主题重复 |
| CSV 必填字段 | 含赛道/人群/核心场景/本地功能 |
| Bridge 七维（H5 shell） | fill 后须齐全 |
| **自拟主题叙事** `theme_audit` | 反泛化、反 CRUD 主卖点、专业锚点 |
| **批内 interactionTopology 重复** | `interaction_topology` ledger |
| **contentpack-registry 相似度** | `audit_task_registry_similarity` |

### theme_audit 拒因码

| 码 | 含义 |
|----|------|
| THEME-001 | 中文主题批内重复 |
| THEME-002 | 核心场景+本地功能 二元组重复 |
| THEME-003 | 主卖点命中 CRUD 套话 |
| THEME-004 | 叙事泛化 / 缺专业锚点 |
| THEME-005 | 中文主题过长或库式长句 |

被拒时打印 **调整推荐清单** + `task-compose-theme` 续跑提示。

## 产包登记

- **登记表**：`data/registry/contentpack-registry.json`
- **写入时机**：`plan.gate` 通过后 `append_to_registry`
- **plan.gate**：文件缺失硬拒；深度/同构 SOFT → `plan_gate_repair` 定向修 1 条（默认 2 轮）
