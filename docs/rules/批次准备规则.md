# 批次准备（task.csv）— 自拟主题版

## 数据源

h5-shell-pipeline **未接入飞书 Bitable**。批前主题来自 **自拟 brief**，不再从主题库抽题。

| 数据 | 来源 | CLI |
|------|------|-----|
| 主题 6 列 | **一句话自拟** | `./run.sh task-compose-theme --row N --text "..."` |
| 全称 / 首个商品Code | 人工或外部看板 | `task-init` 后手填或 compose 后补 |
| Bridge 七维 + topology | 脚本抽牌 | `./run.sh task-fill [--force]` |
| productFlow | topology 模板自动生成 | `task-fill`（勿手写 CRUD 句） |

## 禁止

- **禁止** `task pick-theme` / 主题库抽题作为主路径（已废弃）
- **禁止**读 `43-analysis/` 填主题列
- **禁止**手写 chip→list→export 式 productFlow
- **禁止**在 `task-ready` 未通过前跑产包

## 推荐顺序

```bash
./run.sh task-init --batch-id <batchId> --rows N
./run.sh task-compose-theme --row 1 --text "染发护色追踪档案：记录补色周期…"
./run.sh task-fill --force
./run.sh task-audit
./run.sh task-ready          # 硬拒 + 调整推荐清单
./run.sh --name <App>
```

`task-ready` 失败时会打印 **拒因 + 当前解析 + 调整推荐**，改一句话或 CSV 后重跑即可。

## 校验

- `task-compose-theme --check`：仅解析+叙事校验，不写 CSV
- `task-ready`：CSV 必填、批内去重、topology 唯一、**theme_audit 叙事硬拒**
- 产包中 `plan.gate`：默认软警告 + **定向 repair 续跑**（`STRICT_PLAN_GATE=1` 可全硬拒）
