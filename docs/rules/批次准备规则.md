# 批次准备（task.csv）

## 数据源

当前版本 h5-shell-pipeline **未接入飞书 Bitable**，批次准备流程如下：

| 数据 | 来源 | CLI |
|------|------|-----|
| 全称 / 首个商品Code | 人工从外部表格/看板获取 | `./run.sh task-init` 后手填 |
| 主题库 6 列 + 应用类型 | 人工从外部表格/看板获取 | `./run.sh task-init` 后手填 |
| 新包选题 | 人工确认可用后填入 | `./run.sh task-init` 后手填 |

## 禁止

- **禁止**读 `43-analysis/` 填 `task.csv` 主题或产A 列
- **禁止**手编/猜测 全称、首个商品Code、主题编号 等应对齐在线表的字段
- **禁止**在飞书数据源未对齐前直接 `./run.sh` 跑产包

## 推荐顺序

```bash
./run.sh task-init --batch-id <batchId> --rows N
# 人工填充 task.csv
./run.sh task-validate
./run.sh task-ready
# 然后进入各 Phase 生产
```

## 校验

- `task-validate` / `task-ready` 默认仅做本地校验；后续接入飞书后可增加 `--skip-feishu` 选项用于离线测试。
