# H5 壳产品文档格式（`{全称}.md`）

> **文件名**：与 task.csv `全称` 列完全一致，如 `Mockoo - Steady & Revise.md`  
> **语言**：正文中文；**App Store Listing** 小节英文  
> **参考样例**：Mockoo `Mockoo - Steady & Revise.md`（本格式最新版）  
> **产出步骤**：`build.agent` Part 1，与 `功能文档.md` 同批产出

---

## 填写规则

| 规则 | 说明 |
|------|------|
| H1 与文件名一致 | `#` 标题 = `全称` 列，禁止自创变体 |
| 四级标题 | 四大节用 `####`；演示路线子节用 `#####` |
| 节间分隔 | 产品概述 / Listing / 业务流程 / 演示路线之间用 `---` |
| 与功能文档一致 | 流程、Tab、实体、IAP、差异化与 `功能文档.md` 对齐 |
| 与功能文档分工 | 本文档 = **中文上架叙事 + 审核演示脚本**；`功能文档.md` = **英文实现规格** |
| 演示路线必填 | 含 Step 表、固定数据、覆盖说明、审核 FAQ；禁止空表 |
| 不得占位 | 禁止 TBD / 待补充 / lorem（协议 URL 可暂用占位符） |
