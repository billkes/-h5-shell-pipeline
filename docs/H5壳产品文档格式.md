# H5 壳产品文档格式（`功能文档.md` 内嵌章节）

> **宿主文件**：`功能文档.md`（与英文规格同文件，**不再**单独产出 `{全称}.md`）  
> **语言**：产品概述正文中文；**App Store Listing** 小节英文  
> **产出步骤**：`agent.plan.spec`（与英文规格 + Legal 同步一步）

---

## 在 `功能文档.md` 中的位置

1. 先写完全部 **English 规格章节**（Screen Inventory … §H5 Architecture）
2. 再写 **`#### 产品概述 (Product Overview)`**（中文）
3. 最后写 **`#### App Store Listing`**（英文，全文唯一 Listing 块）

---

## 模板（按序，仅两节 — 嵌入功能文档末尾）

```markdown
#### 产品概述 (Product Overview)

{一段话：产品定位 + 核心能力 + 本地/单机约束}

{一段话：主要功能边界（无社交/无云/无登录等明确否定项）}

**差异化角度（PM Deck：`primaryUserGoal`）**

{一段话：核心目标动词短语 + 与同类 App 的差异；与 CSV `primaryUserGoal` / Interaction Topology 一致}

**受众与场景**

{目标人群 + 典型场合/痛点}

- {主名字} Privacy Agreement: [{隐私政策 URL}]
- {主名字} User Agreement: [{用户协议 URL}]

---

#### App Store Listing

**Subtitle** (≤30 chars)

{英文副标题}

**Promotional Text** (≤170 chars)

{英文推广文案}

**Description**

{完整英文描述，含离线、核心功能、IAP 说明；Shell 为 WebView 时可一句带过 Bridge/在线 H5}

**Keywords** (≤100 chars, comma-separated, no space after comma)

{keyword1,keyword2,keyword3}
```

**Listing 节之后文档结束。** 不要追加其他 `####` 大节。
