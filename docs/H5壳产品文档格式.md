# H5 壳产品文档格式（`{全称}.md`）

> **文件名**：与 task.csv `全称` 列完全一致，如 `Monthio - Habit & Review.md`  
> **语言**：正文中文；**App Store Listing** 小节英文  
> **产出步骤**：`agent.plan.docs`（在 `功能文档.md` 之后）

---

## 模板（按序，仅两节）

```markdown
# {CSV 全称}

#### 产品概述 (Product Overview)

{一段话：产品定位 + 核心能力 + 本地/单机约束}

{一段话：主要功能边界（无社交/无云/无登录等明确否定项）}

**差异化角度（PM Deck：`primaryUserGoal`）**

{一段话：核心目标动词短语 + 与同类 App 的差异；与 CSV `primaryUserGoal` / Interaction Topology 一致}

**受众与场景**

{目标人群 + 典型场合/痛点}

- {主名字} Privacy Agreement: [{隐私政策 URL}]
- {主名字} User Agreement: [{用户协议 URL}]

---

#### App Store Listing

**Subtitle** (≤30 chars)

{英文副标题}

**Promotional Text** (≤170 chars)

{英文推广文案}

**Description**

{完整英文描述，含离线、核心功能、IAP 说明；Shell 为 WebView 时可一句带过 Bridge/在线 H5}

**Keywords** (≤100 chars, comma-separated, no space after comma)

{keyword1,keyword2,keyword3}
```

**文档在此结束。** 不要追加其他 `####` 大节。

---

## 已移除（禁止写入）

| 旧节 | 说明 |
|------|------|
| `#### 业务流程总结 (Business Flow Summary)` | 流程细节见 `功能文档.md`（英文规格） |
| `#### 审核 / 演示路线（点击版）` | 不再在产品文档产出；需要时另建会话文档 |

---

## 填写规则

| 规则 | 说明 |
|------|------|
| H1 与文件名一致 | `#` 标题 = CSV `全称` 列，禁止自创变体 |
| 仅两节 | `#### 产品概述` · `#### App Store Listing`；节间用 `---` 分隔 |
| 与功能文档一致 | 定位、Tab、IAP、差异化与 `功能文档.md` 对齐，但不重复 Screen Inventory 表 |
| 与功能文档分工 | 本文档 = **中文上架叙事 + App Store 文案**；`功能文档.md` = **英文实现规格** |
| 不得占位 | 禁止 TBD / 待补充 / lorem（协议 URL 可暂用占位域名） |
| Listing 英文 | Subtitle / Promotional Text / Description / Keywords 必须英文 |

---

## 样例（节选 · Monthio）

```markdown
# Monthio - Habit & Review

#### 产品概述 (Product Overview)

Monthio 是一款面向成年人的单机习惯追踪与月度复盘应用…

**差异化角度（PM Deck：`primaryUserGoal`）**

核心目标是**在单设备上用「画布式打卡工作台」完成月末习惯复盘**…

**受众与场景**

目标人群：需要追踪长期习惯并进行月度复盘的自我提升者…

- Monthio Privacy Agreement: [https://test.example/monthio/legal/privacy]
- Monthio User Agreement: [https://test.example/monthio/legal/terms]

---

#### App Store Listing

**Subtitle** (≤30 chars)

Habit Track & Month Review

…
```
