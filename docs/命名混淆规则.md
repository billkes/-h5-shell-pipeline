# Naming Obfuscation Rules (v2 — Dynamic Key)

CSV column **命名混淆规则** drives `dartCodePrefix` (package seed) and Agent naming constraints.

## Per-name dynamic generation

命名是一个**纯函数**：

```text
transform_identifier(rule_key, meta, entity, semantic, salt) -> name
derive_key(rule_key, package_seed, entity, semantic, role, length_range, ...) -> affix
```

- **每个 namable 独立调用**：目录、文件、class、method、field、param、local。
- **meta 只存种子**：`ruleKey`、`packageSeed`、`affix`、`lengthRange`、`joinStyles`；**禁止**存 `variableMiddleInsert`、`classSuffix`、`leftRandom` 等可复用缀 key。
- **缀 key 现场派生**：长度在 `lengthRange` 内由 hash 决定（非固定 3 字母）。
- **拼接形态多样**：`camel` / `pascal` / `snake` / `compact` / `dot` / `hyphen`，按 `entity` 选取。

## Featured four rules (主推)

| CSV 名 | ruleKey | 缀位 | lengthRange | 说明 |
|--------|---------|------|-------------|------|
| 辅音核心策略 | `consonant_core` | **前缀** | 2–4 | `key + semantic` |
| 倒序声母策略 | `reverse_initials` | **后缀** | 2–3 | `semantic + key` |
| 单声母三随机策略 | `single_initial_triple` | **中缀** | 2–5 | `head + key + tail`（变长，非固定 3） |
| 双随机镜像策略 | `mirror_random` | **前后缀** | 左 2–3、右 2–3 | `left + semantic + right` |

## Identifier scope

Every rule applies to all namables under `lib/` and raster paths under `assets/` (see exemptions in v1 doc).

Implementation: `scripts/batch/naming.py` — `derive_key`, `transform_identifier`, `RULE_PROFILES`.

## Exemptions

- `lib/main.dart`; scaffold manifest paths.
- Architecture role folder basenames from `architectureFolders`.
- **Native scaffold 固定路径（编组 I / mediaServe，勿混淆为动态命名）**：
  - `ios/{AppName}/SeedBundle/` — Xcode Copy Bundle Resources 内 seed 栅格真源
  - `ios/{AppName}/Bridge/{AppName}SeedAssets.swift` — 类型名用 App 名；`ensureCopied()` 目标路径 `photos/seed/`
  - 标准 persona（美国人/英国人/中国人）保留 `Bridge/` 目录名
- `@override` lifecycle names; Flutter/SDK signatures; loop indices `i/j/k`.
- External JSON/platform keys (document in comment if kept).
