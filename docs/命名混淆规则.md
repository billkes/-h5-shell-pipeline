# Naming Obfuscation Rules (v2 — Dynamic Key)

CSV column **命名混淆规则** drives `dartCodePrefix` (package seed) and Agent naming constraints.

## Per-name dynamic generation

命名是一个**纯函数**：

```text
transform_identifier(rule_key, meta, entity, semantic, salt) -> name
derive_key(rule_key, package_seed, entity, semantic, role, length_range, ...) -> affix
```

- **每个 namable 独立调用**：目录、文件、class、method、field、param、local。
- **meta 只存种子**：`ruleKey`、`packageSeed`、`affix`、`lengthRange`、`joinStyles`；**禁止**存 `variableMiddleInsert`、`classSuffix`、`leftRandom` 等可复用缀 key。
- **缀 key 现场派生**：长度在 `lengthRange` 内由 hash 决定（非固定 3 字母）。
- **拼接形态多样**：`camel` / `pascal` / `snake` / `compact` / `dot` / `hyphen`，按 `entity` 选取。

## Featured four rules (主推)

| CSV 名 | ruleKey | 缀位 | lengthRange | 说明 |
|--------|---------|------|-------------|------|
| 辅音核心策略 | `consonant_core` | **前缀** | 2–4 | `key + semantic` |
| 倒序声母策略 | `reverse_initials` | **后缀** | 2–3 | `semantic + key` |
| 单声母三随机策略 | `single_initial_triple` | **中缀** | 2–5 | `head + key + tail`（变长，非固定 3） |
| 双随机镜像策略 | `mirror_random` | **前后缀** | 左 2–3、右 2–3 | `left + semantic + right` |

## Identifier scope

Every rule applies to all namables under the package source tree:

| Runtime | Scope roots |
|---------|-------------|
| Flutter/Dart | `lib/` + raster paths under `assets/` |
| Swift shell | `ios/{AppName}/**/*.swift` — folders, files, types, members |
| OC shell | `{AppName}/**/*.{m,h,mm}` — folders, files, types, ivars |

Implementation: `scripts/batch/naming.py` — `derive_key`, `transform_identifier`, `RULE_PROFILES`.

### Native shell — every namable (MANDATORY)

Each of the following MUST call `transform_identifier()` independently:

| entity | Swift / OC examples |
|--------|---------------------|
| folder | architecture role dirs, bridge dir, leaf subdirs |
| file | `.swift` / `.m` / `.h` basenames |
| class / struct / enum / protocol | type names |
| method | all methods including private helpers (not SDK protocol requirements) |
| field | stored properties, `@property`, ivars |
| `private let` constant | `private let loadTimeout: TimeInterval = 30` |
| local | `let timeout = …`, `var workItem = …` |
| param | parameter **internal** names when not protocol-mandatory |
| closure param | `{ value in … }` when not trivial `i/j/k` |
| enum case | case identifiers |
| generic param | `T`, `Element` when author-chosen |

**Depth rule**: if a symbol has a semantic English name in template code, it MUST be transformed — including timeout/monitor/queue/workItem/shellReady/fallback copy.

### Flutter/Dart scope (legacy)

Every rule applies to all namables under `lib/` and raster paths under `assets/` (see exemptions below).

## Exemptions

### Flutter/Dart

- `lib/main.dart`; scaffold manifest paths (Info.plist CFBundle* display names only).
- Architecture role folder basenames from `architectureFolders`.
- `@override` lifecycle names; Flutter/SDK signatures; loop indices `i/j/k`.
- External JSON/platform keys (document in comment if kept): Bridge `action` strings, H5 callback channel names.

### Native Swift / OC

- App-name-locked Bridge channel / callback globals (`{appLower}Bridge`, `{appLower}BridgeCallback`) — see H5-Bridge协议.md §5.
- Bridge `action` string literals passed to H5 (external contract keys).
- `@objc` / protocol-required selectors and method signatures (`userContentController(_:didReceive:)`).
- `override` UIKit/WKWebView lifecycle when signature is fixed.
- Loop indices `i`, `j`, `k`.
- Info.plist keys and Asset catalog slot names.

- **Native shell 无固定目录豁免**：`Bridge/`、`SeedBundle/`、`{AppName}*` Swift/OC 类型/文件名均须 `transform_identifier()`（标准 persona 保留 `Bridge/` 目录 basename 时，其内 file/class 仍须混淆）。
