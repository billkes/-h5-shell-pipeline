# 内购合规参考（商品数据不在此文件）

## 商品数据唯一真源（batch 自动生成）

每个 App 工作区在批量启动时会生成：

| 文件 | 含义 |
|------|------|
| `iap-products.json` | 本周全档位 **价格、金币、促销标签**（与 `data/static/iap-products.json` 同步） |
| `iap-catalog.generated.md` | 由 CSV **首个商品Code** 自增生成的 **20 个 productId** + 价金币表 |
| `ios-iap-page-schemes.md` | 内购页规范（复制自 `docs/内购页方案.md`） |

实现与验收时：**只认** `iap-catalog.generated.md` + `iap-products.json`；**禁止**使用旧版 311400 / 324xxx 示例编号或本文件历史表格。

---

## 审核合规（所有包必须遵守）

- **内购类型**：仅允许**消耗型（Consumable）**内购，禁止非消耗型、订阅。
- **消费方式**：按次数扣减；不得「一次购买永久解锁」。
- 应用内不提供「恢复购买」；可展示余额与再次购买入口。

## 编码自增（与 CSV 首个商品Code 一致）

- `00` 为两位自增位，从 `00` 连续到 `18`（12 常规 + 7 促销，常规在前）。
- **后缀式**：`Lattice00` → `Lattice01` … → `Lattice19`
- **前缀式**：`00Lattice` → `01Lattice` … → `19Lattice`

## UI 要点

- 商店页：余额卡片 + **非促销专区** + **限时促销专区**（两区版式不同，见 `ios-iap-page-schemes.md`）。
- 非促销：仅现价；促销：原价 + 优惠价 + 折扣角标。
- 配置 `hot` / `bigDeal` 标签须在 UI 展示（见 `iap-products.json` tags）。

## App Store Connect

- 产品类型须为 **Consumable**；Product ID 与工作区 `iap-catalog.generated.md` 完全一致。
