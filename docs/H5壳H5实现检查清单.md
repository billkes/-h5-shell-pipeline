# H5 Implementer 检查清单（Part 3）

实现范围：**仅** `h5/src/`。工程结构见《H5壳Vite工程规范.md》。

## 禁止

- 编辑 `h5_site/` 部署产物
- 手写 `{prefix}_entry.htm` / legal bundled js / panels
- Flutter Dart UI（除补 h5EntryUrl 常量）
- 业务 H5 打进 Flutter assets
- 外链 legal 作为主展示
- `<input type="file">`、系统 `<select>`、`alert/confirm`
- Tab/Home 暴露 plaza（当 Inventory 含 `#/plaza`）
- 生产代码留 obvious plaza 入口且无 `H5_PLAZA_DEV_ENTRANCE_*` 标记

## 必须

1. 自建完整 `h5/` Vite 树（无仓库代码模板）
2. `h5VaultPattern` 以 `本包登记信息.json` 为准
3. 路由 **仅** Screen Inventory
4. **Plaza**（若在 Inventory）：《H5壳广场页规范.md》；`purchase` 用 `311400`（QA）；dev 入口加 strip 标记
5. **Legal**（若在 Inventory）：《H5壳Legal弹层规范.md》；`sync_h5_legal_bundled.py`
6. **Store**（若在 Inventory）：Bridge `purchase`；catalog 见 `iap-catalog.generated.md`
7. Media：相对路径 + `mediaServe`；大图无 base64
8. 用户可见文案 **English**；日期用 `h5/src/lib/uiLocale.ts`
9. 无 demo CTA（Welcome/Hub/Settings）；onboarding = consent + Continue
10. defaultSeed / pickImage：见 Vite 工程规范
11. Icon：inline SVG sprite；禁 icon font
12. Ambient：`u-{prefix}-ambient` + 视觉蓝图 §Ambient Canvas Canon
13. AppBar/TabBar：TopBar + TabBar + `.page-shell`（layout contract）
14. Overlay hash：《H5壳Overlay路由规范.md》
15. splash（若有）：双 rAF → `shellReady`；无 splash 则在 PM 入口路由 first paint 后调用

## 质量门禁

- Export WYSIWYG · purchase 屏障 · light+dark tokens · `color-scheme: light dark`
- localStorage/Bridge 持久化 · form spellcheck=false
页面视觉细则：`design-system/*/pages/*.md`、`本包视觉锁.json`、Required Reading 所列规范 — **不在 prompt 内重复**。
