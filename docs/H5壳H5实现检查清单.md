# H5 Implementer 检查清单（Part 3）

实现范围：阶段 A `_preview/pages/`（HTML 视觉契约）→ 阶段 B `h5/`（Vue + Tailwind + Phosphor）。  
工程结构见《H5壳Vite工程规范.md》；两阶段细则见《H5壳ui-ux-pro-max使用规范.md》§8。

## 禁止

- 编辑 `h5_site/` 部署产物
- 手写 `{prefix}_entry.htm` / 拆分 css+js 部署树 / legal bundled js / panels（部署仅允许 `h5_site/{appSlug}/index.html`）
- 把 `_preview/pages` 当作部署入口或替代 `h5/`
- 冻结后只改 HTML 不改 Vue（或反向长期分叉）
- Flutter Dart UI（除补 h5EntryUrl 常量）
- 业务 H5 打进 Flutter assets
- 外链 legal 作为主展示
- `<input type="file">`、系统 `<select>`、`alert/confirm`
- Tab/Home 暴露 plaza（当 Inventory 含 `#/plaza`）
- 生产代码留 obvious plaza 入口且无 `H5_PLAZA_DEV_ENTRANCE_*` 标记
- iconfont / Font Awesome / Material Icons
- 另起手写 CSS 体系忽略 `stack-html-tailwind.md`
- 对照其他包 `_preview/` / `h5/` 抄皮

## 必须

### 阶段 A（写 `h5/` 之前）

A1. 按 Screen Inventory 建 `_preview/pages/*.html`（扩展现有 `_preview/`，不另起目录）  
A2. 写 `INDEX.md`（路由 ↔ 文件 ↔ MUST/SHOULD/MAY）  
A3. MUST：Welcome、Tab1/Hub、Primary Export/工作流面（Inventory 有则做）  
A4. 写 `FREEZE.md` 后再进入阶段 B  
A5. HTML 只钉视觉；色板对齐 MASTER / `preview-canonical`（冲突时以 canonical / MASTER 为准）

### 阶段 B（`h5/`）

1. 自建完整 `h5/` Vite 树（无仓库代码模板）
2. 依赖对齐 skill：`vue` · `vue-router` · `tailwindcss` · `@phosphor-icons/vue` · vite-plugin-singlefile
3. 读 `stack-vue.md` + `stack-html-tailwind.md`；token 接 `design-tokens.css`
4. **逐路由对照冻结 HTML 移植**（结构 / Tailwind class 优先原样）；再补业务与 Bridge
5. 图标：Phosphor（`icon-manifest.json` / `icon-brief.md`）——去掉预览临时 CDN 图标方案
6. 字体：MASTER / typography-brief 的 Google Fonts
7. `h5VaultPattern` 以 `本包登记信息.json` 为准
8. 路由 **仅** Screen Inventory
9. **Plaza**（若在 Inventory）：《H5壳广场页规范.md》；`purchase` 用 `311400`（QA）
10. **Legal**（若在 Inventory）：《H5壳Legal弹层规范.md》；`sync_h5_legal_bundled.py`；`legalLinks` 空串 + `openLegal` 运行时分支（有 HTTPS→B07，否则弹层）；**禁**假链占位
11. **Store**（若在 Inventory）：Bridge `purchase`；catalog 见 `iap-catalog.generated.md`
12. Media：相对路径 + `mediaServe`；大图无 base64；业务 PNG **不**进 `h5/public`（壳内 Assets）
13. 用户可见文案 **English**；日期用 `h5/src/lib/uiLocale.ts`
14. Ambient：`u-{prefix}-ambient` + `skill-adapt/ambient-canvas-brief.md`（防批次同款）
15. AppBar/TabBar：layout contract（TopBar + TabBar + `.page-shell`）+ 安全区
16. Overlay hash：《H5壳Overlay路由规范.md》
17. splash（若有）：双 rAF → `shellReady`；非放大空态/Welcome 克隆
18. **Welcome / Hub / Store / Me / Export**：按 `pages/*.md` + topology + 对应 HTML 契约（见下节 Surface Depth）
19. HTML 上示意的主 CTA 在 Vue 中须有可走通的 handler（禁死页面）

## Surface Depth（前置硬约束）

> 实现时**最先遵守**；不是 gate 后置补救。  
> 仅当 Screen Inventory 含对应路由时落地（Welcome / Tab1 工艺条对已列业务面始终生效）。  
> **不含** Legal / Plaza 的视觉加戏——二者只跟专项规范 + 上表必须项。  
> `skill-input/agent-spec-index.md` 会内联 Welcome/Tab1 Scene Brief 摘要。

### Welcome

- 必须落地 `pages/welcome.md` 选定的 Onboarding Pattern（carousel / dialogue / typewriter / narrative / interactive preview）——禁止单屏功能 bullet 卡
- 多步时每拍须**视觉差异化**（布局 / motif / 交互）——禁止三屏同构模板；禁止仅靠表情堆砌区分
- Hero 须有场景化视觉：gradient / blur / keyframes / SVG·插画 / 领域 motif 中 **≥2 种**——禁止仅靠 clip-path 色块或纯文字分步
- 主标题须体现 coreScene / audience——禁止唯一 H1 为 `Welcome to {AppName}`
- 合规区（18+ checkbox + Privacy/User + disabled Continue）仅在最终 beat；Welcome 无 TabBar / 无付费墙
- 与 Splash / MASTER 色弧连贯；禁止无意义纯滚动步
- 尊重 `prefers-reduced-motion`，减动时仍保持层级与氛围

### Tab 1 / Hub

- 首屏 = 本包产品身份（coreScene），不是「KPI 条 + Manage + 空卡片」
- 空状态也要展示 topology 主区骨架 / 预览 motif + 进入 Primary Workflow 的 CTA
- 须有场景化问候（时间或使用情境）——禁止只有静态标签如 `Daily check-ins`
- 功能文档 / Professional Surface 的签名交互须在 Tab1 可见可点
- 主题皮可纯视觉（token / ambient / chrome）**不改** Inventory 拓扑
- 收敛：合并容器、去多余按钮、间距有章法——禁止 SaaS 拼贴
- 禁止 topology 不允许时的 chip+KPI+recent-carousel；禁止 Tab1 放 Bridge plaza
- 清理默认数据勿毁 init；**预设不可删**；用户默认可删

### Primary Workflow / Export

- Tab1 起 ≤2 次点击到达签名编辑→预览→导出（或 Inventory 等价主路径）
- 空态仍有 coreScene 构图 / 预览 motif——禁止空白表单
- Export / Save Flow 列出时：**导出 = 预览**（同构图同比例）——禁止另起一套导出皮
- 禁止写死导出像素 / 临时拉伸凑尺寸；预览必须**看得见**图或构图
- 若有 Standard / HD（或等价），UI 说清差异
- 长 Bridge 操作（拍照 / 相册 / 麦 / 保存）触发控件须有 loading；Inventory 用到的权限须接到真功能
- 控件语言与 kit / Scene Brief 一致

### 其它 Tab-root（Tab2…TabN）

- 一 Tab 一职；禁止复制 Tab1 只改标题
- 空态仍展示该 Tab 专业面（骨架 / motif + CTA）
- Tab 文案 / 图标与 preview-canonical · Inventory 一致
- 禁止双标题（系统标题 + 页内同文 H1）；二级页用**自定义标题样式**（可无底）

### Store（若 Inventory 含商店 / IAP 路由）

- 首屏 = 主题化目录身份（非裸 SKU 表）
- SKU / 价格 / Restore 对齐 `iap-catalog.generated.md` + Bridge `purchase` / restore——禁止硬编码假价
- 购买屏障清晰；Restore 易达
- 布局差异化 + 深浅对比度可读——产品 UI，不是系统设置皮

### Me / Settings（若 Inventory 含）

- 账户 / 恢复购买 / 协议入口枢纽——不是第二首页信息流
- 分区清晰（profile / purchases / about）；禁止照搬 Tab1 KPI 条
- Restore + Privacy/User 入口可见；禁止塞进深层 More
- 密度收敛；二级标题自定义；禁止把 Primary Workflow 编辑器放在 Me

### Splash（若 Inventory 含 H5 splash）

- 品牌短持 → 双 rAF → `shellReady`；禁止假进度条表演
- Motif 对齐 Welcome / MASTER；**禁止**放大版空态或 Welcome 克隆；禁止业务表单

### 工艺条 / 横切

- 色弧 / 造型语言 / 动效来自 MASTER + style-brief / motion-brief + 页面 Scene Brief
- 优先 `c-{prefix}-*` kit + Tailwind；Scene Brief 需要的 motif 扩展进 `kit.css`
- 目标：高级感、创意感、2–3 处有意动效——不是扁平工具页
- **安全区：** 内容勿贴底栏；弹层留左右/底边距（每个 Tab 都查）
- 若有深浅 ambient 背景：遮罩别盖死；底栏慎用 blur（清晰度 / 性能）
- **防抄脸：** 禁止批次同款 Ambient / 欢迎同构；色弧 + 拓扑须本包特异

## 质量门禁

- Export WYSIWYG · purchase 屏障 · light+dark tokens · `color-scheme: light dark`
- localStorage/Bridge 持久化 · form spellcheck=false
