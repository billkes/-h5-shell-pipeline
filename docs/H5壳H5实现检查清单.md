# H5 Implementer 检查清单（Part 3）

实现范围：`h5/`（Vue + Tailwind + Phosphor）。工程结构见《H5壳Vite工程规范.md》。

## 禁止

- 编辑 `h5_site/` 部署产物
- 手写 `{prefix}_entry.htm` / legal bundled js / panels
- Flutter Dart UI（除补 h5EntryUrl 常量）
- 业务 H5 打进 Flutter assets
- 外链 legal 作为主展示
- `<input type="file">`、系统 `<select>`、`alert/confirm`
- Tab/Home 暴露 plaza（当 Inventory 含 `#/plaza`）
- 生产代码留 obvious plaza 入口且无 `H5_PLAZA_DEV_ENTRANCE_*` 标记
- iconfont / Font Awesome / Material Icons
- 另起手写 CSS 体系忽略 `stack-html-tailwind.md`

## 必须

1. 自建完整 `h5/` Vite 树（无仓库代码模板）
2. 依赖对齐 skill：`vue` · `vue-router` · `tailwindcss` · `@phosphor-icons/vue` · vite-plugin-singlefile
3. 读 `stack-vue.md` + `stack-html-tailwind.md`；token 接 `design-tokens.css`
4. 图标：Phosphor（`icon-manifest.json` / `icon-brief.md`）
5. 字体：MASTER / typography-brief 的 Google Fonts
6. `h5VaultPattern` 以 `本包登记信息.json` 为准
7. 路由 **仅** Screen Inventory
8. **Plaza**（若在 Inventory）：《H5壳广场页规范.md》；`purchase` 用 `311400`（QA）
9. **Legal**（若在 Inventory）：《H5壳Legal弹层规范.md》；`sync_h5_legal_bundled.py`
10. **Store**（若在 Inventory）：Bridge `purchase`；catalog 见 `iap-catalog.generated.md`
11. Media：相对路径 + `mediaServe`；大图无 base64
12. 用户可见文案 **English**；日期用 `h5/src/lib/uiLocale.ts`
13. Ambient：`u-{prefix}-ambient` + `skill-adapt/ambient-canvas-brief.md`
14. AppBar/TabBar：layout contract（TopBar + TabBar + `.page-shell`）
15. Overlay hash：《H5壳Overlay路由规范.md》
16. splash（若有）：双 rAF → `shellReady`
17. **Welcome / Hub**：按 `pages/welcome.md` · `pages/hub.md` + topology

## 质量门禁

- Export WYSIWYG · purchase 屏障 · light+dark tokens · `color-scheme: light dark`
- localStorage/Bridge 持久化 · form spellcheck=false
