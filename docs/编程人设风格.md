# 编程人设风格（Native Swift/OC 实现维度）

> CSV 列 **编程风格** 驱动 `programmingStyle`。本文定义 **dims 2–5（代码怎么写）** 对 Swift/OC 壳的实现约束。
>
> - **dim-1 Widget split**：Flutter-only，native 壳 **不适用**。
> - **dims 6–7 libLayout / assetLayout**：由 `programming_layout.py` + `本包资源布局.json` 管辖目录与 H5 vault 拓扑，**不**决定控制流。
> - **Bridge 七维**：管辖 bridge **机制**（做什么）；persona dim-4 只决定围绕已锁机制的 **写法**（guard/async 形态），不得改写 `bridgeDeckSelections`。

## 使用方式

1. 在 CSV 查到 `编程风格` persona 名。
2. 在下方矩阵找到对应行，将 dims 2–5 应用到 **所有壳 Swift/OC 源文件**。
3. 与《命名混淆规则.md》正交：persona 改写法，命名改标识符拼写。

## 维度定义（Swift/OC）

| Dim | 名称 | 管辖 |
|-----|------|------|
| 2 | Style / access | `let` vs `var`、`private`/`fileprivate`、stored vs computed |
| 3 | Syntax & iteration | `map/filter` vs `for-in`、trailing closure、`guard` 密度 |
| 4 | Control flow & async | `DispatchWorkItem` vs `Timer` vs `Task`/`async` vs Combine；early-return 策略 |
| 5 | Method split & optional | 方法粒度、`if let`/`guard let`/`??`/force-unwrap 偏好 |

## 矩阵（7 persona × dims 2–5）

### 美国人

| Dim | Swift/OC 约束 |
|-----|---------------|
| 2 | 默认 `private let` 常量；可变状态用 `private var`；偏好 stored property |
| 3 | 标准 `for item in items`；必要时 `map`；trailing closure 适度 |
| 4 | **`DispatchWorkItem` + `DispatchQueue.main.async`** 做超时/延迟；`guard` early-return 为主 |
| 5 | 中等方法粒度（20–40 行）；`guard let` 解包 optional；禁止 force-unwrap |

### 英国人

| Dim | Swift/OC 约束 |
|-----|---------------|
| 2 | `fileprivate` 多于 `private`；computed property 展示派生状态 |
| 3 | 偏好 `compactMap`/`filter` 链式；闭包参数显式命名 |
| 4 | **`Timer.scheduledTimer`** 做 loadTimeout / fallback；`if` 嵌套 ≤2 层 |
| 5 | 小函数拆分（≤25 行）；`if let` 嵌套解包；提取 `private func validate…()` |

### 德国人

| Dim | Swift/OC 约束 |
|-----|---------------|
| 2 | 严格 `private`；最少 `var`，能用 `let` 不用 `var` |
| 3 | 显式 `for` 循环多于 functional；避免过度链式 |
| 4 | **`DispatchWorkItem` cancel 语义** + 专用 serial queue；深度 `guard` 链 |
| 5 | 细粒度方法（≤15 行）；每个分支独立函数；`guard let` + `else { return }` |

### 法国人

| Dim | Swift/OC 约束 |
|-----|---------------|
| 2 | `private(set) var` 暴露只读；computed 优先于 stored |
| 3 | Trailing closure 优先；`forEach` 处理副作用 |
| 4 | **`Task { @MainActor in … }` / `async`**（Swift）或 GCD main queue（OC）做异步；混合 `guard` 与 `if return` |
| 5 | 按职责拆 extension（`// MARK:`）；`??` 提供默认值；optional map |

### 俄罗斯人

| Dim | Swift/OC 约束 |
|-----|---------------|
| 2 | 最少属性；局部 `let` 优先；`lazy var` 延迟重型对象 |
| 3 | 简单 `while`/`for`；少 higher-order |
| 4 | **单一路径**：一个 serial `DispatchQueue` 承载 monitor + timeout；禁止多层 async 交叉 |
| 5 | 大函数可接受（≤50 行）但逻辑线性；`if let` 顺序解包；少提取 |

### 日本人

| Dim | Swift/OC 约束 |
|-----|---------------|
| 2 | 明确访问级别注释；`private` 默认；常量集中 `enum Constants` |
| 3 | 命名闭包参数；`for-in` + 早期 `continue` |
| 4 | **`OperationQueue` + `BlockOperation`** 或 `DispatchWorkItem`；超时与 monitor 分类型 |
| 5 | 一方法一职责（≤20 行）；`guard let`；错误路径独立 `private func` |

### 中国人

| Dim | Swift/OC 约束 |
|-----|---------------|
| 2 |  pragmatic `internal` 辅助类型；`let`/`var` 混用 |
| 3 | 混用 `map` 与 `for-in`；OC 用 block 迭代 |
| 4 | **`Timer` + `DispatchWorkItem` 组合**（Timer 触发，WorkItem 取消）；扁平 `if return` |
| 5 | 中等粒度；`??` 与 `guard let` 并用；提取重复 switch 为方法 |

## Flutter-only 台账字段（native 非绑定）

以下字段出现在 `本包维度锁.json` 但 **不约束** Swift/OC 壳实现：

- `dartPackageName`
- `stateManagement`（如 `provider`）
- `programmingStyle.libLayout` / `skinBucket`（无 `lib/` 实体）
- `programmingStyle.assetRoots`（Flutter pubspec 专用）

Native 壳须对齐：`architectureFolders`、`namingObfuscationRule`、`bridgeDeckSelections`、本文 dims 2–5。
