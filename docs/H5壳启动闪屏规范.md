# H5 壳启动闪屏规范

`h5_shell` 冷启动须 **无黑屏闪帧**。禁止仅用 `ColoredBox` 改色遮盖；须按**时序**根治。

> **LaunchScreen 占位图（1125×2436）** 由本流水线写入；**真实启动页**替换不在 A 面流水线范围。

## 时序（目标）

```
iOS LaunchScreen（1125×2436 占位静态图）
  → Flutter 首帧 LaunchVeil（同图续接）
  → WebView 挂载（透明，在 Veil 下 loadRequest(h5EntryUrl)）
  → 远程 H5 splash 双 rAF → bridge shellReady
  → 撤 LaunchVeil，露出已绘制的 WebView
```

### 组件层约定

- **Flutter 壳侧**：只保留 iOS `LaunchScreen.storyboard`；**禁止** Flutter Splash Widget
- **H5 侧**：首屏 veil DOM，与 LaunchScreen 同图；`shellReady` 后 CSS opacity 淡出
- **触发信号**：以 `shellReady` 为准，不用 `onPageFinished` 当首屏可见信号

## Flutter 壳（Programmer 必做）

1. **`main()` 立即 `runApp`** — 禁止 `await VaultBoot.warm()` 再 `runApp`。
2. **`{Prefix}VaultBoot.warm()`** 在 `MaterialApp` 的 `initState` 异步执行（mediaServe / Bridge 预热）。
3. **预热完成前** `home` 显示 `{Prefix}LaunchVeil`（与 LaunchScreen **同占位图**）。
4. **`{Prefix}PathVaultHost`**：`Stack(WebViewWidget, LaunchVeil)`；`pagePainted` 为 true 且挂载后一帧再撤 Veil。
5. **WebViewController**：`WebKitWebViewControllerCreationParams` + `addJavaScriptChannel` **先于** `loadRequest`；`setBackgroundColor(Colors.transparent)`。
6. **首屏 URL**：从 `本包登记信息.json` 读 `h5EntryUrl`（开发 `h5EntryUrlDev` / 上线 `h5EntryUrlProd`）。
7. **Bridge** 处理 `shellReady` → `pagePainted = true`（不用 `onPageFinished` 当首屏可见信号）。
8. **加载失败**：英文 Retry（重新 `loadRequest`）；**不**假装离线可用。

## iOS（Programmer 必做）

1. **`{Prefix}FlutterViewController`**：`loadView` 绑定 `splashScreenView` ← LaunchScreen storyboard。
2. **LaunchScreen.storyboard**：全屏 **1125×2436** 占位图（`launchPlaceholderAsset` → Native imageset）；与 LaunchVeil 同资源。**禁止**在 `h5/assets/{prefix}_launch/` 再留副本。
3. **Main.storyboard**：`customClass="{Prefix}FlutterViewController"`；FlutterView `backgroundColor` 透明。
4. **AppDelegate**：`window?.backgroundColor = .clear`。
5. **ATS**：Release 允许配置的 H5 生产域名；Debug 可允许局域网 HTTP。

模板见 `data/static/templates/h5_*.template`。

## H5（Implementer 必做）

1. **entry head**：内联 `window.appNative` 包装 `window.appNative.postMessage`（JS channel 名**统一**为 `appNative`，与 Dart 一致；H5 多包复用时不随壳代码 prefix 变化）。
2. **`boot()` 立即执行** — 禁止 `setTimeout(boot, …)` / `paaowNativeReady` 事件兜底。
3. **splash `afterMount`**：双 `requestAnimationFrame` 后 `bridge.call('shellReady', {})`。
4. H5 部署在 **`h5SiteRoot`**，由壳 `h5EntryUrl` 加载 — **不**打进 Flutter assets。

## Swift 壳（Programmer 必做）

`h5_swift_shell` 目标时序与 Flutter 壳一致，实现方式替换为 Swift/UIKit：

1. **`LaunchScreen.storyboard`**：全屏纯色或 1125×2436 占位图，与 H5 首屏背景一致。
2. **`{{APP_NAME}}App.swift`**：`@main` 入口；启动后立即挂载根 `UIViewController`，显示 `{{APP_NAME}}LaunchVeil`。
3. **`WebViewController`**：
   - 创建 `WKWebView` 时背景透明。
   - `viewDidLoad` 中 `loadRequest(h5EntryUrl)`。
   - Bridge 收到 `shellReady` 后，延迟一帧再撤 Veil。
4. **加载失败**：英文 Retry 页，点击重新 `loadRequest(h5EntryUrl)`。

详细代码与配置见《H5壳Swift实现规范.md》§6。

## Gate 软警告

- `setTimeout(boot` in site
- 缺 `shellReady` 调用
- Flutter 缺 LaunchVeil / 自定义 FlutterViewController
- `main()` 在 `runApp` 前 `await warm`
- 壳仍 `loadFlutterAsset` 而无 `loadRequest`
- 缺 `h5EntryUrl` 登记字段
