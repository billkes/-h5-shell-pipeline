# H5 去风味规范

H5 纯血实现，但**体验与观感须像原生 iOS App**，不能露网页/浏览器味。本文是 `h5_shell` 的**体验与过审风控**主文档；上架前与《H5壳H5实现检查清单.md》及《H5壳Pack约束.md》一并勾选。

**分工约定（已定稿）**

| 层 | 职责 |
|----|------|
| **Flutter 壳** | 主 WebView 容器、Bridge、加载/无网兜底（无 Welcome/Legal Widget） |
| **H5（混淆 vault，`bundleVaultDir`）** | 全部业务 UI、**顶栏 AppBar**、路由、交互、去风味 CSS 基线 |

H5 **必须自带**统一去风味样式（`polish.css` 或等价内联），**不由壳注入**。

---

## 0. 为什么去风味（4.2 + 4.3 须「记起来」）

去风味不是美化，是**降低审核员与真实用户识别「套壳 H5」的概率**，并避免性能问题触发拒审。

### 0.1 Guideline 4.2 — 最小功能（套壳拒审）

Apple 原文要点：

> App 应包含功能、内容和 UI，而不仅仅是一个经过重新包装的网站。若 App 没有什么实用价值、毫无新意或者不太像是一个 App，则不适合出现在 App Store。

**审核员常见套壳信号**（与去风味直接相关）：

- Web 式 loading、系统滚动条、浏览器式顶栏随内容滚动
- 长按放大镜、拼写红波浪线、H5 原生 `<input type="file">` 底部选项框
- 键盘遮挡输入框、大图 base64 导致卡顿
- 无网时整页不可用（仅靠远程 URL）
- 主体验与 Safari 打开同一站点无差别

**h5_shell 抵消 4.2 的硬性要求**（见 §8）：除去风味外，须提供**壳 + Bridge 原生能力**，使 App 超越「仅重包装网站」。

### 0.2 Guideline 4.3 — 重复/相似（模板同源）

项目内要点见下文与《H5壳Pack约束.md》壳侧差异化；**勿**出产包工作区去读外仓 4.3 专文。要点：

| 4.3 关切 | 与 H5 去风味的关系 |
|----------|-------------------|
| **(b) 与现有应用无区分** | 4.3 差异化由 **Flutter 壳**承担；H5 交互、组件、顶栏、滚动体感**统一即可**，不因此判定模板同源 |
| **代码相似度** | Flutter 壳有维度抽卡（Bridge 七维、命名混淆、架构文件夹、编程人设）；**H5 不差异化**，多包可共用同一套未改动的 H5 模板 |
| **meaningfully different** | 去风味是底线；壳侧 Bridge 能力组合、代码组合须可区分（登记表 `contentpack-registry`） |

工具包常规「至少 3 Tab」——**h5_shell 不适用**；以 §8 原生抵消清单 + **壳侧差异化**（Bridge 七维 / 命名 / 架构 / 人设）替代。

### 0.3 性能与 4.2 的交叉风险

- **>3MB 图片 base64 读写**：主线程卡死 → 审核认为「低质/不可用」→ 4.2
- **键盘盖住输入框无法输入**：核心流程不可用 → 4.2 / 2.1
- **首屏长时间白屏或 Web 转圈**：不像 App → 4.2

## 1. H5 统一基线（`polish.css` — 必须自带）

H5 vault 须引入统一基线（可拆 `polish.css`，或在 `index.html` 内联等价规则）。**禁止依赖壳注入**。

```css
/* polish.css — 统一基线模板，各包共用同一份，不可删核心规则；禁止按主题改色 */

/* 1) 禁长按放大镜 / 文本选择（输入框除外） */
html, body, *:not(input):not(textarea) {
  -webkit-touch-callout: none;
  -webkit-user-select: none;
  user-select: none;
}
input, textarea {
  -webkit-touch-callout: auto;
  -webkit-user-select: auto;
  user-select: auto;
}

/* 2) 禁点击灰底高亮 */
* { -webkit-tap-highlight-color: transparent; }

/* 3) 禁系统滚动条 */
::-webkit-scrollbar { display: none; width: 0; height: 0; }

/* 4) 禁页面横向滚动 */
html, body { overflow-x: hidden; -webkit-text-size-adjust: 100%; }

/* 5) 安全区（与 viewport-fit=cover 配合） */
:root {
  --safe-top: env(safe-area-inset-top, 0px);
  --safe-bottom: env(safe-area-inset-bottom, 0px);
}
```

`index.html` 头部还须：

```html
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no, viewport-fit=cover">
```

### 1.5 L0 Reset（原生标签去风味）

`app_baseline.css` 首段 MUST 覆盖 §2–§7 所列原生标签默认行为，且至少包含：

| 项 | 规则 |
|---|---|
| box-sizing | `border-box` 全局 |
| margin / padding | 裸标签清零（组件自行定义） |
| tap-highlight | `-webkit-tap-highlight-color: transparent` |
| touch-callout / user-select | 非 input/textarea 禁选区与放大镜 |
| scrollbar | `::-webkit-scrollbar { display: none }` |
| overflow-x | `html, body { overflow-x: hidden }` |
| text-size-adjust | `-webkit-text-size-adjust: 100%` |
| safe-area | `:root` 声明 `--safe-top/bottom: env(safe-area-inset-*)` |
| overscroll | `overscroll-behavior: none`（按需） |

**禁止**删核心 reset 规则。

**Checkbox / Radio 例外（MANDATORY）：** 全局 `appearance: none` 仅适用于文本类 input，须排除 checkbox/radio（见 §3 行 9–10）。Welcome 门闸 checkbox 在 hero 背景上必须可见。

### 1.6 L1 Tokens（设计变量）

`:root` 内声明 `--app-color-brand`、`--app-radius-*`、`--app-space-*`、`--app-font-*`。数值采用**项目统一设计 token**，**不随包/主题变化**；**禁止**硬编码散落色值替代 token。

### 1.7 L2 Primitives（Atoms · 14 项基线）

项目统一 kit 须含可复用 atoms（按统一命名规范）：

`btn/press/action/tap`、`input/field/entry/type`、`chip/tag/pill/mark`、`card/tile/panel/cell`、`appbar/topbar/bar/header`、`modal/dialog/overlay/veil`、`toast/notify`、`mark/icon`。

DOM 骨架采用项目统一标准（如 label-span-inner / text-only / leading-icon-span / wrapper-div），**不随包变化**。

### 1.8 L3 Composites（Molecules）

由 atoms 组合：`list-row`、`form-field`、`empty-state`、`hero`、`store-row` 等。Screens（L4）**只引用 composites + primitives**，不得 inline 大段样式。

### 1.9 裸标签禁止 + Kit 统一规范

| 规则 | 说明 |
|------|------|
| **裸标签** | 业务 HTML 禁止 styled 裸 `<button>`/`<input>`/`<a>`；须带 kit 类 |
| **kit 规范** | 项目统一 kit（CSS/JS/DOM），**不抽卡、不差异化** |
| **H5 arch** | 项目统一状态模型 / 路由 / 屏架构，**不抽卡、不差异化** |
| **Flutter 列** | `状态管理` / `架构模式` / Bridge 七维 仅壳；勿与 H5 arch 混用 |
| **登记** | `本包登记信息.json` 中 `kitDeckSelections`、`h5StateModel`、`h5RouterPattern`、`h5ScreenPattern` 固定为项目默认值 |
| **跨包** | H5 站点可跨包复用，不触发 Jaccard 软警告 |

### 1.10 H5 业务架构（统一规范）

| 项 | 落盘 |
|----|------|
| 状态模型 | entry/panels JS 状态读写方式（项目统一） |
| 路由 | 屏切换 / 返回 / URL 策略（项目统一） |
| 屏组织 | panel 文件组织（controller / template / class / render fn）（项目统一） |

功能文档.md 可省略 **§H5 Architecture** 映射表；如需保留，统一填写项目默认值。

## 2. 触控与选择（禁 H5「网页手感」）

| # | 禁忌（一眼像 H5/Web） | 必须做法 |
|---|----------------------|----------|
| 1 | **长按页面/输入框出现放大镜** | 全局 `-webkit-touch-callout: none`（§1）；输入框单独 `auto`；`img/a` 加 `oncontextmenu="return false"` |
| 2 | 长按弹出「拷贝/查询」菜单 | 同 §1；链接若不需拷贝，禁 `user-select` |
| 3 | 双击文字放大 | `maximum-scale=1, user-scalable=no` |
| 4 | 点击按钮灰色闪一下 | `-webkit-tap-highlight-color: transparent` + 自绘 `:active` 态 |
| 5 | 按钮热区 < 44pt | 所有可点区域 `min-height: 44px; min-width: 44px`（或等效 padding） |

## 3. 输入与键盘

| # | 禁忌 | 必须做法 |
|---|------|----------|
| 4 | **键盘弹出盖住输入框，页面不滚，无法输入** | ① `input`/`textarea` `focus` 时 `element.scrollIntoView({ block: 'center', behavior: 'smooth' })`；② 可滚容器设 `padding-bottom: calc(var(--safe-bottom) + 键盘高度)`（监听 `visualViewport` resize）；③ 表单页用**单列表单布局**，避免 `position:fixed` 挡住焦点 |
| 5 | **输入框下方红色拼写波浪线** | 所有 `input`/`textarea`：`spellcheck="false" autocorrect="off" autocapitalize="off" autocomplete="off"` |
| 6 | iOS 18 滑键/QuickType 反复提示 | 同上；必要时 `inputmode="text"` |
| 7 | 首字母自动大写干扰 | `autocapitalize="off"` |
| 8 | 语音输入麦克风按钮 | `input::-webkit-input-speech-button { display: none; }` |
| 9 | **Welcome 同意 Checkbox 不可见** | **禁止**对 `input[type=checkbox]` / `input[type=radio]` 全局 `appearance: none`。文本类 input 去原生样式须写 `input:not([type="checkbox"]):not([type="radio"])`。hero 渐变背景上须 native checkbox 或 custom 白底描边样式，对比度 ≥4.5:1 |
| 10 | Welcome 合规文案过小 | 18+ / 协议勾选区 **禁止** `--font-micro` / bodySmall (11px)；下限 **labelMedium (14px)** |

## 4. 滚动与顶栏 AppBar（Q1：由 H5 绘制）

| # | 禁忌 | 必须做法 |
|---|------|----------|
| 3 | **滚动时出现系统滚动条** | `::-webkit-scrollbar { display: none }`；内嵌滚动区同样处理 |
| 6 | **AppBar 随页面一起滚走（像浏览器）** | 顶栏 **`position: fixed; top: 0; left: 0; right: 0; z-index: 1000`**；内容区 `padding-top: var(--appbar-height)`；**禁止**把顶栏放在可滚 `document.body` 流内 |
| — | 整页橡皮筋 | 按产品：可依赖壳 `scrollView.bounces`；H5 内列表用 `overflow-y: auto` 自管 |
| — | 横向意外滚动 | `overflow-x: hidden` |
| — | 双滚动嵌套错乱 | 明确**单一主滚动容器**；避免 `body` 与内层同时 `overflow: scroll` |

**AppBar 结构建议（H5）**

```
┌─ fixed appbar (safe-area top) ─┐
│  [←]  Title        [action]   │
├─ scrollable content ───────────┤
│  ...                           │
└─ safe-area bottom ─────────────┘
```

## 5. 禁用 H5 原生组件（必须自绘或走 Bridge）

| 禁用 | 典型表现 | 替代 |
|------|----------|------|
| `<input type="color">` | 系统颜色选择器 | 自绘色盘 / 预设色 Chip |
| `<input type="date">` / `type="time">` | iOS 滚轮日期 | 自绘日期/时间 picker |
| `<input type="file">` | **底部相机/相册选项框**（#7） | Bridge `pickImage` / `pickVideo`，Flutter 弹**原生**相册相机 |
| `<select>` | 底部滚轮选项 | 自绘全屏/半屏 sheet 列表 |
| `window.alert` / `confirm` / `prompt` | 系统样式弹窗 | 自绘 Modal（英文文案） |
| `window.print()` | 打印对话框 | Bridge 导出/分享 |
| 右键/长按菜单 | 保存图片/打开链接 | `preventDefault` + 业务自定义菜单 |

**原则**：凡 iOS 会以**系统底部 sheet / 滚轮 / 浏览器控件**呈现的，一律不用 H5 原生标签。

## 6. 媒体与文件（禁 base64）

| 规则 | 说明 |
|------|------|
| **严禁 base64 存图/读图展示** | 相机相册图常 >3MB，base64 解码阻塞主线程 → 页面卡死 → 4.2 |
| **正确链路** | 上传 → Bridge `pickImage` → Flutter 存 `Documents/相对路径` → 回传相对路径 → H5 用 `mediaServe` 方案 URL 显示（见《H5壳业务流程文字版.md》§1.6） |
| **持久化** | 业务库/JSON **只存相对路径**，不存 base64、不存绝对路径 |
| **缩略图** | 可用壳侧生成小图或限制分辨率；仍走文件 URL，非 base64 |
| **视频/音频** | 同上，走 Bridge + 沙盒文件 |

## 7. 壳侧配合（Flutter / WebView）

H5 负责交互与视觉；壳负责**容器级**去浏览器味：

| 项 | 要求 |
|----|------|
| 无浏览器 chrome | 无地址栏、刷新、前进后退 |
| 全屏 | WebView 铺满；H5 自管 safe-area |
| 过渡 | Splash/Welcome 底色 = H5 首屏底色，防白闪 |
| 加载态 | 禁长时间空白；H5 骨架屏或壳短暂占位 |
| 滚动条 | `showsVerticalScrollIndicator = false`（辅助 §4） |
| 外链 | Bridge `openExternalUrl`，禁止主 WebView 裸跳 |
| 加载失败 | 原生英文 Retry 页（重新 loadRequest），禁 WK 默认错误页 |
| 在线首屏 | 壳 `loadRequest(h5EntryUrl)`；Bridge 原生能力（相机/相册/录音/IAP）为 4.2 价值点 |

### 7.1 Swift 壳去风味补充

Swift 侧容器级处理：

| 问题 | 实现 |
|------|------|
| 系统滚动条 | `webView.scrollView.showsVerticalScrollIndicator = false` |
| 双击缩放 | 注入 JS `touch-action: manipulation`；或 swizzle 禁用双击手势 |
| 键盘辅助栏 | swizzle `WKWebView` / `WKContentView` 的 `inputAccessoryView` 返回 `nil` |
| WebView 背景 | 设 `.clear` 或与首屏同色，避免 Veil 撤除后闪白 |
| 链接长按菜单 | H5 侧 `oncontextmenu="return false"` |

> 警告：german_persona 模板使用 method swizzle 修改 `WKWebView.init` 与 `UIView.addGestureRecognizer`，具有全局侵入性。新包若采用 swizzle，须评估是否影响应用内全部 `WKWebView` 实例。

详细实现见《H5壳Swift实现规范.md》§7。

## 8. 4.2 抵消清单（原生能力 — PM 须在功能文档列出 ≥3 项）

去风味是**必要条件**；通过 4.2 还须证明「不只是网站包装」。以下能力由**壳/Bridge**提供，H5 调用：

| 能力 | 4.2 价值 |
|------|----------|
| H5 Welcome 门闸 + Bridge 原生能力 | 合规、非纯 Web 登录流 |
| 相册/相机（Bridge B01） | 设备能力；浏览器走 `browserMock` 假成功调 UI，真机 Plaza 验权 |
| 文件沙盒读写（Bridge B05） | 本地持久化 |
| StoreKit IAP（Bridge B09） | 应用内经济，非网页支付 |
| 推送（若启用） | 平台能力 |
| 生物识别（若启用） | 原生安全 |
| **Bridge 原生能力（相机/相册/录音/IAP）** | 4.2 证明非纯网页包装 |

PM 在 `功能文档.md` **「4.2 Native Offset」** 小节列出本包启用的 ≥3 项及用户可见场景。

## 12. 交付自检（勾选）

### 触控
- [ ] 长按页面/图片/非输入区无放大镜、无系统菜单
- [ ] 按钮热区 ≥ 44pt

### 输入
- [ ] 所有输入框无拼写红波浪线（`spellcheck="false"` 等）
- [ ] 键盘弹出后当前输入框滚入可见区，可继续输入

### 滚动与顶栏
- [ ] 滚动时无系统滚动条露出
- [ ] **AppBar `position:fixed`，不随内容滚动**

### 组件
- [ ] 无 `<input type="file/color/date">`、无 `<select>` 系统样式
- [ ] 相机/相册走 Bridge，无 H5 底部选项框
- [ ] 无 `alert/confirm/prompt`
- [ ] **无 `<audio controls>`**；音频走自定义 `AudioPlayer`（隐藏原生控件）

### 媒体
- [ ] 图片上传/展示无 base64；仅相对路径 + `mediaServe` URL
- [ ] >3MB 图不卡死
- [ ] **录音（若启用）**：录完可回放；优先原生录音链路；无 err -50 / 有录无播

### 底栏与安全区（20260721）
- [ ] 主列表滚到底 **不贴死 Dock**（`padding-bottom: calc(dock + safe-area)`）
- [ ] Modal / Sheet 有左右边距 + 底部 `safe-area-inset-bottom`
- [ ] `viewport-fit=cover` + safe-area 变量已配置

### 基线
- [ ] `polish.css`（或等价）已引入 `index.html`

### 过审记项
